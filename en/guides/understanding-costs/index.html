Estimate the cost of completed tasks

Translate token rates, account credits, and failed attempts into a budget you can reconcile.

Separate money from usage units

Check the exact model’s input, output, cache-write, cache-read, tool, and media charges. Confirm currency, taxes, minimum top-ups, expiry, and any multipliers. Cache storage or writing need not share the rate charged for reading cached tokens.

If an account sells credits, obtain the conversion explicitly. For a hypothetical 100 credits per dollar, 250 credits mean $2.50 before fees. Do not assume a displayed quota is a token count or that bonus credits are refundable.

Calculate an explicit hypothetical

Assume invented rates of $2 per million input tokens and $8 per million output tokens. A request containing 3,000 input and 1,000 output tokens costs $0.006 + $0.008 = $0.014. One thousand identical requests cost $14 before extras. These are not current provider prices.

Calculate cache writes and reads separately using their documented units. Check whether reported cached tokens are included in total input, rather than adding them twice. Compare an uncached request with a confirmed cache hit instead of assuming a discount applies.

Audit failure charges

Retries, abandoned streams, and repeated context increase cost per accepted result. Ask whether timeouts, rejected requests, and partial generations are charged; a client error does not establish that upstream processing stopped.

Keep request identifiers, response usage, timestamps, and balance movements for a small controlled trial. Compare completed, rejected, and interrupted requests. Request clarification for unexplained deductions before increasing traffic, and avoid creating destructive or excessive failure tests.

Set a purchasing boundary

Estimate monthly spend from task volume, observed retries, and accepted-result cost, then add a testing reserve. Configure alerts and hard limits where supported; verify whether limits stop requests or only send notifications.

Reconcile the ledger against local records and retain the applicable tariff. Check refund deadlines, fees, invoice eligibility, and the issuing entity in writing. A directory flag cannot establish which unused funds or documents you are entitled to receive.
