Translated description

Positioning: BRO coding (https://brocod.ing) is a multi-model AI API platform. With one account, users can call mainstream models including GPT, Claude, Gemini, Grok, DeepSeek, and GLM. It supports online chat and an OpenAI-compatible interface (/v1). Key advantages: Each model is connected to multiple upstream providers and automatically switches in the event of failure. New upstream providers undergo authenticity checks before onboarding; replaced models or non-compliant channels are automatically taken offline. All models include built-in web search, with the model deciding whether to search. Service features: Web chat and the standard API use the same account; the /ping page publicly displays real-time status and pricing for each model; usage-based billing with no mandatory plans. Pricing: Pricing is public and transparent, based on model and upstream costs, and visible on the page.
