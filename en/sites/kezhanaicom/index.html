Featuring a wuxia inn theme, the site brings model selection, key management, account top-ups, usage queries, and after-sales support together in one place, helping users get started with AI more conveniently and understand usage costs more clearly. - Centralized multi-model management for easier access. View models, interface types, and prices in the “藏经阁,” and select appropriate capabilities as needed; users can conduct online conversations in the “问剑台” or create API Keys to integrate models into their own applications and workflows. The platform provides integration guides and code examples, reducing the effort from choosing a model to completing the first call. - Top up as needed and pay by usage, with clear accounts. The model directory displays pricing for the selected group, while invocation records can be used to verify models, usage, and costs. Availability and response speed of specific models remain subject to upstream services, networks, and concurrency conditions. - After-sales support is accessible and handling can be tracked. For account login, top-up billing, or model integration issues, users can submit tickets through “飞鸽传书,” add details, view handling status and replies, and access centrally stored communication history. The platform also provides individual and enterprise invoice application access, supporting review progress queries and PDF invoice downloads after approval. - Balances usage management with the long-term experience. Supports creating independent API Keys per application, configuring quotas, validity periods, model permissions, and IP restrictions. It also includes check-in, invitation, and growth benefit features, allowing users to view currently available activities and applicable rules on the site. The wuxia inn style runs throughout the experience, giving the tool platform a distinctive and friendly character.

客栈 AI（kezhanai） 是一个集多模型调用、在线对话与 API 接入于一体的 AI 服务平台，面向开发者、内容创作者，以及希望将 AI 接入日常工作和业务应用的个人与团队。站点以武侠客栈为特色，将模型选择、密钥管理、账户充值、用量查询和售后支持集中在一处，让用户更方便地开始使用 AI，也更清楚地掌握使用成本。 - 多模型集中管理，接入更方便。 在“藏经阁”查看模型、接口类型与价格，按需求选择适合的能力；既可以在“问剑台”进行在线对话，也可以创建 API Key，将模型接入自己的应用和工作流。平台提供接入手册及代码示例，减少从选模型到完成首次调用的操作成本。 - 按需充值、按使用计费，账目清楚。 不同模型根据 Token 用量、调用次数或对应计价规则结算，模型目录展示所选分组的价格，调用记录可核对模型、用量与费用。用户可以结合预算选择模型，并为不同应用设置独立令牌额度。具体单价、缓存及附加费用，以站内价格说明和最终账单为准。 - 重视服务稳定性，也提供问题排查入口。 项目通过渠道管理、实际调用验证、部署健康检查和备份恢复机制维护服务，并提供“驿路状态”、服务公告与调用日志，帮助用户检查连接、了解服务调整和定位异常。具体模型的可用性与响应速度仍受上游服务、网络及并发情况影响。 - 售后有入口，处理过程可追踪。 遇到账户登录、充值账务或模型接入问题，可以通过“飞鸽传书”提交工单、补充说明、查看处理状态与回复，历史沟通集中保存。平台还提供个人及企业发票申请入口，支持审核进度查询和审核完成后的发票 PDF 下载。 - 兼顾使用管理与长期体验。 支持按应用创建独立 API Key，配置额度、有效期、模型权限及 IP 限制；同时设有签到、邀请和成长权益功能，用户可在站内查看当前开放的活动及适用规则。武侠客栈风格贯穿整个使用过程，让工具平台多一份辨识度与亲切感。
