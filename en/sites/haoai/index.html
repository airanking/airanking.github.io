Gateway profile

hao.ai: Current public-data score: 49.9, with 100% field coverage. Uptime 55%; latency 4.1 s. hao.ai is a unified large-model API gateway for developers and teams. It supports access to mainstream AI models such as GPT, Claude, and xAI Grok through a single API Key, and is compatible with commonly used protocols and SDKs such as OpenAI, Anthropic, and xAI Grok. The platform is suitable for AI application development, coding assistants, automation tools, content generation, internal enterprise systems, and other scenarios, helping users reduce the cost of multi-model integration and maintenance. hao.ai features include OpenAI-compatible interfaces, common APIs such as Responses / Chat Completions, OpenAI Responses WebSocket persistent connection support, a web-based Chat experience, a multi-model catalog, model price comparison, model routing, failover, and invocation logs. The platform provides complete invocation detail records. Users can view the model, API Key, invocation time, input/output usage, cache usage, cache hit rate, latency, status, error information, and cost details for each request, facilitating cost accounting, troubleshooting, and usage analysis. hao.ai supports team management capabilities. Teams can centrally manage members, API Keys, wallet balances, and usage permissions, and set different budgets and limits for teams, members, or API Keys, making it suitable for multi-person collaboration and internal enterprise projects. In terms of pricing, hao.ai uses a pay-as-you-go model. Users can use different models based on actual usage without separately maintaining accounts across multiple model platforms. The platform provides clear model pricing displays and comparisons with official reference prices, helping users evaluate costs across different models. In terms of service, hao.ai provides Chinese documentation, API documentation, integration tutorials, and technical support, covering common development tools and clients such as Claude Code, Codex, Cursor, Cherry Studio, and Chatbox, helping users quickly complete integration and troubleshoot issues.
