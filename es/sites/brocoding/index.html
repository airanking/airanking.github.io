Descripción de origen

定位：BRO coding（https://brocod.ing）是多模型 AI API 平台，一个账号即可调用 GPT、Claude、Gemini、Grok、DeepSeek、GLM 等主流模型，支持在线对话和 OpenAI 兼容接口（/v1）。 主要优势：每个模型接入多个上游，故障时自动切换；新上游接入前做真实性检测，替换模型或不合格的渠道自动下线；所有模型内置联网搜索，由模型自行决定是否搜索。 服务特点：Web 对话与标准 API 同一账号；/ping 页面公开各模型的实时状态与价格；按量计费，不强制套餐。 价格：价格公开透明，按模型和上游成本定价，页面可见。
