Perfil del gateway

客栈AI: Puntuación basada en datos públicos: 33,1, con una cobertura del 70 % de los campos. Disponibilidad 79,5%; latencia 8,6 s. 客栈 AI (kezhanai) es una plataforma de servicios de IA que integra llamadas a múltiples modelos, conversación en línea y acceso API. Está dirigida a desarrolladores, creadores de contenido y personas o equipos que desean incorporar IA a su trabajo diario y aplicaciones de negocio. El sitio se caracteriza por una posada de estilo wuxia y centraliza la selección de modelos, gestión de claves, recarga de cuenta, consulta de uso y soporte posventa, permitiendo a los usuarios comenzar a utilizar IA más fácilmente y comprender mejor sus costos de uso. - Gestión centralizada de múltiples modelos para una integración más sencilla. En la “Biblioteca de Sutras” se pueden consultar modelos, tipos de interfaz y precios, y elegir las capacidades adecuadas según las necesidades. Es posible conversar en línea en la “Plataforma de Preguntas de Espadas” o crear una API Key para integrar los modelos en aplicaciones y flujos de trabajo propios. La plataforma proporciona manuales de integración y ejemplos de código para reducir el esfuerzo desde la elección del modelo hasta la primera llamada. - Recarga según las necesidades y facturación por uso, con cuentas claras. Los distintos modelos se liquidan según el uso de Token, número de llamadas o las reglas de precio correspondientes. El catálogo de modelos muestra los precios del grupo seleccionado y los registros de llamadas permiten verificar el modelo, uso y costo. Los usuarios pueden elegir modelos según su presupuesto y configurar límites de tokens independientes para distintas aplicaciones. Los precios unitarios específicos, caché y cargos adicionales estarán sujetos a las instrucciones de precios del sitio y a la factura final. - Da importancia a la estabilidad del servicio y también proporciona vías para investigar problemas. El proyecto mantiene el servicio mediante gestión de canales, validación de llamadas reales, comprobaciones de salud de la implementación y mecanismos de copia de seguridad y recuperación. Además, ofrece “Estado de la Ruta”, anuncios de servicio y registros de llamadas para ayudar a los usuarios a comprobar conexiones, conocer ajustes del servicio y localizar anomalías. La disponibilidad y velocidad de respuesta de cada modelo siguen sujetas a los servicios upstream, la red y la concurrencia. - El soporte posventa tiene un canal de atención y el proceso puede rastrearse. Ante problemas de inicio de sesión, recargas, facturación o integración de modelos, se pueden enviar tickets mediante “Paloma Mensajera”, añadir explicaciones y consultar el estado de procesamiento y las respuestas; el historial de comunicaciones se guarda de forma centralizada. La plataforma también proporciona canales para solicitar facturas personales y empresariales, consultar el progreso de revisión y descargar la factura en PDF tras completar la revisión. - Equilibra la gestión de uso y la experiencia a largo plazo. Permite crear API Key independientes por aplicación y configurar límites, fecha de validez, permisos de modelos y restricciones de IP. También incluye funciones de registro diario, invitaciones y beneficios de crecimiento; los usuarios pueden consultar en el sitio las actividades abiertas y las reglas aplicables. El estilo de posada wuxia está presente durante todo el proceso de uso, aportando mayor identidad y cercanía a la plataforma de herramientas.

Descripción de origen

客栈 AI（kezhanai） 是一个集多模型调用、在线对话与 API 接入于一体的 AI 服务平台，面向开发者、内容创作者，以及希望将 AI 接入日常工作和业务应用的个人与团队。站点以武侠客栈为特色，将模型选择、密钥管理、账户充值、用量查询和售后支持集中在一处，让用户更方便地开始使用 AI，也更清楚地掌握使用成本。 - 多模型集中管理，接入更方便。 在“藏经阁”查看模型、接口类型与价格，按需求选择适合的能力；既可以在“问剑台”进行在线对话，也可以创建 API Key，将模型接入自己的应用和工作流。平台提供接入手册及代码示例，减少从选模型到完成首次调用的操作成本。 - 按需充值、按使用计费，账目清楚。 不同模型根据 Token 用量、调用次数或对应计价规则结算，模型目录展示所选分组的价格，调用记录可核对模型、用量与费用。用户可以结合预算选择模型，并为不同应用设置独立令牌额度。具体单价、缓存及附加费用，以站内价格说明和最终账单为准。 - 重视服务稳定性，也提供问题排查入口。 项目通过渠道管理、实际调用验证、部署健康检查和备份恢复机制维护服务，并提供“驿路状态”、服务公告与调用日志，帮助用户检查连接、了解服务调整和定位异常。具体模型的可用性与响应速度仍受上游服务、网络及并发情况影响。 - 售后有入口，处理过程可追踪。 遇到账户登录、充值账务或模型接入问题，可以通过“飞鸽传书”提交工单、补充说明、查看处理状态与回复，历史沟通集中保存。平台还提供个人及企业发票申请入口，支持审核进度查询和审核完成后的发票 PDF 下载。 - 兼顾使用管理与长期体验。 支持按应用创建独立 API Key，配置额度、有效期、模型权限及 IP 限制；同时设有签到、邀请和成长权益功能，用户可在站内查看当前开放的活动及适用规则。武侠客栈风格贯穿整个使用过程，让工具平台多一份辨识度与亲切感。
